# Deprecated functions

Deprecated functions

## Usage

``` r
mbrest(...)

adm_lines(...)

obs_lines(...)

use_posterior(...)
```

## Arguments

- ...:

  passed to the corresponding function

## Details

- mbrest() is now
  [`mapbayest()`](https://felicienll.github.io/mapbayr/reference/mapbayest.md)

- adm_lines() is now
  [`adm_rows()`](https://felicienll.github.io/mapbayr/reference/adm_rows.md)

- obs_lines() is now
  [`obs_rows()`](https://felicienll.github.io/mapbayr/reference/obs_rows.md)

- use_posterior() is defunct. Most features are available using
  [`use_estimates()`](https://felicienll.github.io/mapbayr/reference/use_estimates.md)
