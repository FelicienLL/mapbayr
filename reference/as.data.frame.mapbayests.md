# Return the mapbay_tab as a data.frame

Return the mapbay_tab as a data.frame

## Usage

``` r
# S3 method for class 'mapbayests'
as.data.frame(x, row.names = NULL, optional = FALSE, ...)
```

## Arguments

- x:

  A `mapbayests` object.

- row.names, optional, ...:

  passed to as.data.frame

## Value

a data.frame (the mapbay_tab from estimation)
